# Lean 白鄉村麵包・練習系列（進行中）

> **這不是實驗系列，是練習系列。** 目的不是「找出最佳配方」，
> 而是**把配方固定住，練到自己的判斷穩定**——練的是發酵判讀與手法，不是配方。

## 為什麼是這個麵包

Trevor Wilson 的變因排序：**發酵 ≈ 麵團手法 ＞＞＞ 水合**（麵粉也在後段）。
要練前兩名，就得把所有干擾拿掉：

| 拿掉的東西 | 為什麼 |
|---|---|
| **全麥** | 麩皮切筋、刺破氣室，壓低氣孔天花板（troubleshooting §0） |
| **配料**（乾果堅果） | 塊狀物打斷筋網、降低 oven spring |
| **配方變動** | 每爐都改，就永遠不知道進步的是技術還是配方 |

剩下的失敗**只可能是發酵或手法**——這就是練習麵團的意義。
（同時它也順便回答了「這套技術＋這台氣炸烤箱的上限在哪」。）

## 基準配方（**固定不動，不要每爐改**）

總粉 320 g／總水 224 g ＝ **總水合 70%**

| 材料 | 克數 | 備註 |
|---|---|---|
| **波蘭種** | 白粉 100 ＋ 水 100 ＋ 速發酵母 **1 g** | 快啟動冷藏型（酵母 1%）：室溫 1～2h 充分啟動→進冷藏過夜 |
| 主麵團粉 | 白粉 **220** | 一支粉用到底，不混不換 |
| 主麵團水 | **124** | 總水 224／總粉 320 ＝ **70%** |
| 鹽 | **6 g** | 約 1.9% |

**粉的選擇**（挑一支，然後**整個系列都用它**）：
- 🚨 **練習期用輥磨白粉，不要用石磨高灰分粉**——見下方 9/10、9/11 的教訓
- **首選：水手牌特級強力粉 13% / 0.40**（輥磨、超高吸水、你的基準粉、容錯最高）
- ⚠️ **避開凱薩琳**（11.6%/0.35）：你自己的四國粉實驗把它歸在「難做大孔」那格
- ⏳ **石磨 T65（布爾喬亞／布瑟）等技術穩了再用**：風味最好，但**酵素活性最高、容錯最低**，
  在台灣 30°C 室溫是 hard mode

### 為什麼從 70% 起，不是 74%

1. **文獻：一般開放組織約 70% 水合就做得到**，不需要高水合（troubleshooting §0）
2. **好操作＝能專心練判斷**——70% 不會逼你一直搶救癱軟的麵團，
   注意力才放得回「發酵到了沒」
3. **水合是 distant third**：先把前兩名練穩，再回頭加水才有意義
4. **70% 若做不出開放組織 → 水合確定不是問題**，直接排除一個變因

**什麼時候才往上加水**：連續 2～3 爐剖面的「壁」都是薄脊、bulk 判斷不再猶豫之後，
再一次 +2%（70 → 72 → 74）。**技術沒穩就加水，得到的是皮下巨洞不是開放組織**
（troubleshooting §五）。

## 流程（每爐照走，不要改）

1. **前一晚**：波蘭種混合 → 室溫 1～2h 啟動 → 冷藏過夜
2. **當天**：`ddt.py` 算水溫（目標**麵團溫度 24～26°C**）→ autolyse 主麵團粉＋水 **30 分**
   （主麵團是純白粉，30 分即可，不必拉長）
3. 加波蘭種＋鹽，混合
4. **主發酵**：摺疊 4 次（每 30 分一次）→ **發到 1.8～2 倍**
   > 🚨 **商業酵母走 1.8～2 倍，不是酸種的雙因子法**——那張表這裡不適用
5. 預整形 → bench rest 20～25 分 → 整形
6. 最後發酵（室溫或冷藏擇一，**整個系列固定同一種**）
7. **加蓋 13 分 → 開蓋 200°C 18 分 → 180°C 8 分**，中心 **96～98°C**
8. **完全放涼至少 1 小時**再切

排程倒推：`python3 scripts/ferment.py schedule --at "出爐時間"`

## 每爐一定要記的五件事

**沒記這五項的那一爐等於白做**——因為無法解釋結果。

| 項目 | 怎麼記 |
|---|---|
| 1. **麵團溫度** | 攪拌完插溫度計。⚠️ **不是室溫**，兩者常差 1～3°C |
| 2. **bulk 實際漲幅與時數** | 直壁透明容器＋橡皮筋標線，讀倍數不讀時鐘 |
| 3. **最後發酵判斷** | 戳洞測試的反應（快彈／慢彈留痕／不回彈） |
| 4. **中心溫度** | 探針，96～98°C |
| 5. **剖面照** | ⚠️ **單一平整切面正對鏡頭**（掰開對拍會產生假的分層帶） |

## 練習重點（按 Wilson 排序，一次專心練一項）

### 🥇 第一階段：練 bulk 終點判讀

**這是最可疑也最高報酬的一項。** 08-18 那爐主發酵只有 45～50 分、未達 2 倍，
當時判為「無不足徵象」用的是**已被駁回的判準**——所以它到底夠不夠，其實還沒確認過。

練法：**每 30 分拍一次側面照＋記漲幅**，一路記到你決定收手為止。
出爐後回頭對照剖面，校正自己的眼睛。

**驗收標準：剖面的「壁」是薄脊還是塊**（troubleshooting §0 強制步驟）——
不是看孔大不大、多不多。

### 🥈 第二階段：練手法

摺疊力道與時機、預整形張力、整形收口。這階段會開始出現
「同樣的發酵判斷，成品卻更挺、氣孔更均勻」——那就是手法在進步。

### 🥉 之後才談：加水、換粉、加全麥、加配料

**每次只加回一樣。** 加回全麥時記得：不是不能做，只是更難——
可用篩麩皮＋soaker 回加（troubleshooting §0）。

### 🚨 f1／f2 失敗診斷：麵筋降解（proteolysis），不是筋沒建立

**決定性證據**：f2 是 **70% 水合、純白粉、只有 0.3% 酵母**——這個條件攤成麵糊，
**不可能是水太多**。而且兩爐都出現同一個模式：

| | 筋還沒建立 | **筋正在降解** |
|---|---|---|
| 摺疊後 | **逐次改善** | 暫時收住，**撐住時間越來越短** |
| 越摺 | 越好 | **越糟** ← f1「摺完 5 次表面反而更粗糙」、f2「摺完又變粗糙、攤開很快」 |

**三個疊加因素**：

1. **🥇 麵團溫度過高**——室溫 30°C，麵團大概率 30～32°C。
   逼近 32°C 時 **protease 極度活躍，麵筋 30～60 分內從完美崩到救不回來**。
   ⚠️ **protease 的時鐘與產氣的時鐘是分開的**：氣可能還沒發滿，筋已經被吃掉
   → 表現為「**沒發起來卻又攤掉**」，最容易被誤判成「筋不夠、該多摺」（而多摺只會更糟）。
2. **🥈 石磨 T65 的酵素活性**——石磨保留更多胚芽麩皮＝更多 protease。
   此款自述「石磨粉酵素較多、主發酵比純白粉快」，在 30°C 被放大。
3. **🥉 波蘭種可能已過頭**——30°C 室溫發酵後進冷藏，降溫期仍續發；
   過頭的波蘭種把大量酵素與酸帶進主麵團，是 ①② 的加速器。**兩爐都有**。

**流程層面的根本問題**：**兩爐都沒量麵溫、沒標線量漲幅**
→ 無法區分「發過頭」與「筋不夠」（症狀都是攤，對策卻相反）。
上面的診斷是**推論不是實測**，下一爐補上這兩項才能驗證。

### f3 的處方（彙整版，2026-09-11 定案）

> **根本問題一句話：把 8 月用一般高筋粉調出來的水合數字，
> 直接搬到一支吸水低得多的法國粉上，沒有換算。**

| 項目 | 數值 | 依據 |
|---|---|---|
| **總水合** | **65%** | **69%**（8 月全白實測上限）**− 5pp**（T65 低吸水） |
| 波蘭種 | **水手** 100 ＋ 水 100 ＋ 酵母 **0.5g** | 把水的負擔放在吸水的粉上（f1 原設計就是對的） |
| 主麵團 | T65 220 ＋ **水 108** ＋ 鹽 6 | |
| **水** | **冰水** | 8 月食譜自己寫的「用冰水是夏天壓麵溫」，f1/f2 都漏掉 |
| **麵團溫度** | **24～26°C**，攪拌完量 | `ddt.py --target 25 --room <室溫> --flour-temp <粉溫>` |
| 環境 | **開冷氣** | |
| 摺疊 | **摺到不再有回應就停**（不是固定次數） | 見下方修正 |
| 容器 | **直壁透明＋標線** | 沒有它就是盲飛 |

不夠濕就**後加水，一次 10g，記下實際用量**——那個數字才是這支粉的真正基準。

### 成因排序（f1／f2 綜合）

1. **🥇 有效水合超出已驗證上限約 6pp**——唯一能單獨解釋「70% 純白粉攤成麵糊」的原因
2. **🥈 沒控麵溫**——30°C 室溫，8 月食譜寫的冰水沒用；石磨粉酵素多會放大
3. **🥉 酵母量是驗證過配方的 2.5 倍**（0.31% vs 0.125%）
4. **流程**：沒量麵溫、沒標線 → 讓失敗變成**不可診斷**

### ⚠️ 修正：摺疊次數不是固定數字

原本寫「減到 3 次」是**基於 proteolysis 假設，照片出來後不成立**。正確規則是**看回應**：

| 摺完的反應 | 意思 | 做法 |
|---|---|---|
| 變挺、撐住時間**變長** | 筋在建立 | ✅ 繼續摺 |
| 收得回去但撐住時間**一次比一次短** | 筋在降解 | ❌ 停手 |
| 幾乎沒差別 | 到頂了 | 停手 |

> 摺疊動作本身不是壞事，**壞的是「每多摺一次就多 20 分鐘泡在 30°C 裡」**——時間成本才是問題。

### 📌 這次真正的教訓（已寫進 SKILL.md 強制檢查）

1. **給數字前先翻使用者自己的紀錄**——**答案 8 月就在檔案裡（69%）**，沒人去翻。
   使用者早就試出來的值 **>** 從文獻推的值 **>** 印象。
2. **換變因時數字要換算不能沿用**——已驗證的數字綁在當時的條件上。
   ⚠️ 最危險的是「帳面上更保守」的變動（拿掉全麥、水合 −2%，有效水合其實 +5～8%）。
3. **推薦麵粉必問操作環境溫度**——不能只看蛋白質 × 灰分兩維度，
   第三維是**容錯度**（石磨／高灰分＝風味最好、酵素最高、容錯最低）。

**AI 這次的四個失誤**：推薦 T65 沒問環境溫度／練習系列基準訂 70% 沒查 T65 吸水差異也沒翻舊紀錄／
第一次診斷判成 proteolysis（照片一出來即不成立）／開 62.5% 矯枉過正低於正常區間。
