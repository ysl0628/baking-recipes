# 麵團整型指南（張力是一切）

> 整形唯一的目標：**在不過度破壞氣泡的前提下，把表面繃出一層緊的「皮」（表面張力）**。
> 挺不挺、割線開不開，一半在發酵、一半就在這層皮。

## 0. 先分清兩條路線

| | 歐包路線（留氣孔） | 甜麵包／吐司路線（細緻均勻） |
|---|---|---|
| 筋性建立 | **摺疊養筋**（免揉/少揉，主發酵期間摺，守則見 rustic-bread.md §5） | **攪拌出膜**（筋在攪拌階段完成，主發酵不摺疊，頂多翻面排氣一次） |
| 排氣 | **輕柔不排氣** ✅實測 | **確實排氣**（拍掉大泡） |
| 目的 | 保住發酵氣泡 → 開放組織 | 打散大泡 → 均勻細緻組織 |
| 手感 | 像捧豆腐 | 像揉黏土 |

用錯路線的代價：歐包排氣過度＝組織細密像饅頭；甜麵包不排氣＝剖面大洞不均。

## 一、預整形（preshape）——歐包流程

- **時機**：bulk 到約 1.8 倍後，倒出麵團。
- **手法**：檯面薄撒粉，刮板＋手輕收成**鬆散的圓**，不壓、不排氣 ✅實測。
- **鬆弛 15～30 分**（蓋布防乾）。目的：讓筋放鬆，最終整形才收得緊而不撕裂。
- 時間看筋性：筋弱/小麵團 15～20 分夠；筋強/大麵團往 30 分抓。
- 鬆弛夠了的判斷（比計時準）：麵團微微攤開、輕按不太回彈；還很緊繃就再等。

## 二、最終整形：圓形 boule（氣炸烤箱主力）

1. 光面朝下，輕拉四邊往中心摺（像包包袱），成一個粗略的包。
2. 翻面（收口朝下、光面朝上）。
3. 雙手小指側貼檯面圍住麵團，**往自己的方向拖拉**——底部與檯面的摩擦會把表面繃緊。
4. 轉 90°，重複拖拉 2～3 輪，到表面緊繃光滑、按下去有彈性。
5. **繃到緊就停**：表面開始要破、看得到氣泡膜快撐破＝過頭了，再拉會漏氣。
6. 入藤籃／碗墊布：**收口朝上**（烤時倒扣後收口朝下）、籃內確實撒粉。

> 防黏粉最有效的是**米粉：麵粉 = 1:1**（米粉不吸水不黏）；只用麵粉容易黏籃毀掉表面。

## 三、橢圓 batard（簡述）

預整形同上。最終整形：光面朝下拍成橫向橢圓 → 上緣往中間摺、按實 → 左右角往內收 →
由上往下**捲**進來，邊捲邊用掌根壓實收口 → 收口朝上入籃。適合割單刀直線，爆口比圓形好看。

## 四、高水合麵團對策（70%+）

- **濕手 vs 手粉**：摺疊、bulk 內操作用**濕手**；整形（需要摩擦力建張力）用**薄手粉**。
- 檯面粉越少越好——粉多了麵團打滑，拖拉建不起張力。
- **動作快、次數少**：猶豫地摸十次不如果斷地收三次，摸越久越黏。
- 刮板是第二隻手：鏟、翻、收都用它，減少手直接接觸。
- **整形站不住 ≠ 撒粉不夠** ✅實測：那是筋不夠或水太多——回去補摺疊，或下次降水合（hydration.py），狂撒粉只會把生粉夾進麵團。

## 五、小餐包滾圓／吐司擀捲（簡述）

- **滾圓**：分割後手掌罩住麵團，掌心貼檯面畫圓，靠虎口和檯面摩擦把表面收緊到底部一點。檯面要**幾乎無粉**（太滑滾不緊）。收口捏合朝下排盤。
- **吐司擀捲**：排氣擀平 → 捲起 → 鬆弛 15 分 → 轉 90° 再擀捲一次（二次擀捲組織才細）→ 收口朝下入模。捲的鬆緊一致，太緊烤時頂部撕裂、太鬆有空洞。

## 六、整形照片判讀（使用者傳整形階段照片時看這節）

拍法：**側面**（看挺度：高度 vs 攤開程度）＋**俯視**（看表面與收口）。

| 照片特徵 | 判讀 | 下一步 |
|---|---|---|
| 表面光滑、緊繃、微微反光 | 張力足 ✅ | 入籃/進最後發酵 |
| 鬆垮攤開、表面粗糙無光 | 張力不足或筋太鬆 | 再收 1～2 輪；還是垮→鬆弛 15 分重新整形 |
| 表面破洞、看得到氣泡膜被撐破 | 張力拉過頭 | 停手，破口朝下入籃；下次早點停 |
| 預整形後明顯攤開、按壓不回彈 | 鬆弛到位 | 進最終整形 |
| 預整形後還高挺、按壓快回彈 | 鬆弛不夠 | 再等 5～10 分，硬整會撕裂 |
| 收口處開縫、沒捏合 | 收口不實 | 捏緊再入籃（不處理會側爆） |

高水合麵團「站不住」的判讀提醒：**是筋不夠，不是粉不夠**（§四）——照片裡看到檯面大量手粉
＋麵團仍攤，建議回頭補摺疊，不是繼續撒粉。

## 七、常見錯誤對照

| 錯誤 | 後果 | 修正 |
|---|---|---|
| 撒粉太多夾進麵團 | 剖面有生粉線、組織分層 | 檯面薄粉；黏就用刮板不用加粉 |
| 張力拉過頭、表皮破 | 破口處烤時亂爆、漏氣 | 表面緊繃光滑就停手 |
| 收口沒捏緊 | 側爆、底部裂開 | 收口確實捏合，朝正確方向擺 |
| 排氣過度（歐包） | 組織細密像饅頭 ✅實測 | 全程當豆腐捧，只在表面做張力 |
| 整形完又戳又補 | 消泡、表面破相 | 一次到位；失敗就重新鬆弛 15 分再整一次 |
| 藤籃沒撒夠粉 | 倒扣黏籃、表面毀掉 | 米粉:麵粉 1:1 撒足；高水合麵團更要多 |
