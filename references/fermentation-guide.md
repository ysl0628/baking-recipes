# 發酵判斷指南（看狀態，不看時鐘）

> 溫度每差 8°C，發酵時間就差一倍（`scripts/ferment.py adjust`）——所以食譜寫的時間只是鬧鐘，
> **出爐與否永遠看狀態**。台灣夏天尤其如此：食譜時間 ×0.6～0.7 就要開始檢查。

> ⚠️ **給 AI：環境溫度必問，不准猜**。發酵時間、酵母量、水溫全都由它決定，而使用者的環境
> **每次都可能不同**（冷氣房 vs 室溫、不同房間、不同季節）——上次的溫度不是這次的溫度，
> 不可沿用。排程或算量前若沒拿到溫度就**先問**；若必須先給草案，明確標示假設值並列出
> 「若實際為 X 則改為 Y」的對照，等使用者回報後定案。

## 一、Bulk（主發酵）怎麼判斷

**起算點**：主發酵從**主麵團材料混合完成**開始計算（不是摺疊做完才開始）——摺疊本身就是主發酵
期間的動作。摺疊的時機與停手守則見 rustic-bread.md §5。

按可靠度排序：

1. **體積**（最可靠）：用直壁透明容器＋橡皮筋標起始高度，肉眼直接讀倍數。
   - **商業酵母麵團**（波蘭種/直接法/佛卡夏）：歐包 Cold Proof 抓 **1.8 倍**再整形 ✅實測
     （進冷藏還會續發，別發滿 2 倍才進）；直接法室溫流程抓 2 倍。
   - **酸種（天然酵母）麵團：終點低很多，且看麵團溫度決定**——見下方雙因子法。
   - 圓盆看不準倍數——這就是要用直壁容器的原因。

### ⚠️ 酸種專用：雙因子法（Two-Factor Method，麵團溫度 × 漲幅）

酸種 bulk 的終點**不是固定倍數，是溫度的函數**——溫度越高，越要提早收（高溫下酸度發展與
結構劣化都比產氣快）。來源：The Sourdough Journey（Tom Cucuzza）數百次實驗。

| 麵團溫度 | 停在漲幅 | 約需時間 |
|---|---|---|
| 27°C | **僅 +30%** | 3.5～5.5h |
| 24°C | +50% | 5～7h |
| 21°C | +75% | 8～12h |
| 18°C | +100%（翻倍） | 12～16h |

- **台灣夏天 30°C+ 外推：約 +20～25% 就該收**——遠早於「快翻倍」。
- **最常見的酸種失敗＝拿商業酵母的「發到兩倍」標準套用在酸種上**，在高溫更是必翻車。
- 對策不只是早收：**控麵溫**（`scripts/ddt.py` 用冰水把麵溫壓到 24～26°C）比追漲幅更根本。
- 判準仍要交叉：漲幅＋邊緣拱起＋jiggle＋表面氣泡，不單看一項。
2. **Aliquot jar 法**（進階）：攪拌完取一小球麵團塞進窄小量杯同環境放，主麵團不動、看小杯讀倍數。摺疊多次的麵團特別適用（摺疊會壓掉主容器的讀數）。
3. **表面與手感**：表面出現氣泡、邊緣往上拱出圓弧、輕搖容器會晃動（jiggle）、聞起來有發酵香。
4. **拉開底部看**：輕拉麵團邊緣，內部呈蜘蛛網狀＝筋和氣體都到位。

## 二、最終發酵：戳洞測試（poke test）

指腹沾粉，在麵團側面按下約 1cm：

| 按下去的反應 | 判讀 | 動作 |
|---|---|---|
| 快速彈回、不留痕 | 發酵不足 | 再等 15～20 分重測 |
| **緩慢回彈、留下淺痕** | **剛好** | **進爐** |
| 不回彈、或按了洩氣 | 過發 | 立刻進爐搶救，一分鐘都別再等 |

**冷藏麵團（Cold Proof）戳洞不準** ✅實測：麵團又冷又緊實，回彈慢是低溫造成的，不代表發好。
判斷改看**體積（明顯膨起）＋表面氣泡**，到了就不退冰直接倒扣、割線、進爐。

## 三、過發 vs 不足 對照

| | 發酵不足 | 剛好 | 過發 |
|---|---|---|---|
| 外觀 | 緊實、小、無氣泡 | 膨、表面有氣泡、輕晃會動 | 塌軟、表面大泡或塌陷 |
| 氣味 | 沒什麼味道 | 發酵香、微酸 | 酒味、刺鼻酸 |
| 戳洞 | 快彈回 | 慢彈回留淺痕 | 不回彈／洩氣 |
| 烤後 | 組織緊密、爆裂亂 | 挺、割線開 | 扁、無 oven spring、酸 |

**補救**：
- 不足 → 單純再等（環境冷就放烤箱＋一杯熱水）。
- 過發 → 不可逆。輕手重整形改做佛卡夏／披薩／扁麵包，別強求挺度；嚴重過發（酸臭、癱）只能當老麵用掉（doughs.md 法式老麵）。

## 四、麵種成熟判斷

- **波蘭種（白粉）**：表面滿布氣泡、**中心微微塌陷**、拉開有絲、微酸的酒香 → 熟了就用。
  塌很深＋酒味重＝過頭——還能用，但風味偏酸、活性降，主麵團可略補酵母。
- **全麥/裸麥麵種：表面氣泡少是正常，不是沒發**——麩皮切筋鎖不住氣，氣泡浮到表面就破，
  加上糊體稠、氣更難頂出來（與 float test 假不合格同一機制）。判讀改看三信號：
  **罐壁氣泡**（側面照為主）＋**體積漲幅**＋**氣味轉微酸酒香**；表面只會蓬鬆帶破泡痕，
  等「表面滿布氣泡」會等過頭。
- **進冷藏的時機 ≠ 使用的時機（降溫滯後）**：容器進冰箱後中心要 1～2 小時才降到發酵近停，
  這段時間**還在續發**。馬上要用 → 等顛峰微塌；**要冷藏過夜 → 顛峰前就進**，讓降溫期＋冷藏
  緩發走完最後一段，別在室溫等到塌頂才冰（明早必過頂：偏酸、發力降）。
- **波蘭種分兩型，判準不同**：低酵母過夜型（0.1～0.2%，室溫 12～16h 慢養，等中心微塌）vs
  **快啟動冷藏型（約 1%，室溫 1～2h 充分啟動就進冷藏**，rustic-bread §3 基準流程即此型）。
  看酵母量認型，別拿過夜型的「等塌頂」套在快啟動型上。
- **Levain（酸種）**：體積翻倍＋**頂點微微回落前**用，活性最好（sourdough-starter.md §3）。
  到頂時間估算：`python3 scripts/starter_feed.py --keep 30 --ratio 1:5:5 --temp 32`
- 沒空等到剛好？寧可**略早**用（活性在上升段），不要過頂太久。

## 五、照片回報判讀協議（通用：酵種／麵種／主麵團都適用）

使用者會用照片＋文字回報發酵狀態，收到就照這節判讀。

**拍照 SOP（判定準不準一半取決於這裡）**
- 開始發酵時在容器外**標記起始高度**（橡皮筋/膠帶，寫上時間更好——照片自帶記錄）
- 拍兩張：**側面**（正對容器，同時看到標記線和目前高度；氣泡判讀主力）＋**俯視**（表面狀態）
- **固定條件**：同一個直壁透明容器、同角度同距離、光線充足避免背光
- 照片模糊/背光/沒拍到標記時，AI 應**請使用者重拍或口頭補充**，不硬猜

**視覺特徵判定表**

| 狀態 | 側面照特徵 | 俯視照特徵 |
|---|---|---|
| 未啟動 | 高度≈標記線、質地緊實、容器壁無氣泡 | 表面平坦無泡 |
| 剛啟動 | 壁面零星針尖小泡、高度微升 | 表面稀疏小泡 |
| 活躍上升 | 壁面滿布大小氣泡、高度明顯爬升 | 表面拱起、蓬鬆感增加 |
| **顛峰** | 高度到頂（對照該比例/酵母量的預期）、氣泡最密 | 圓頂剛轉平、質地如慕斯 |
| 過頂回落 | **壁面有高於目前高度的殘漬水位線**（最可靠證據）、高度下降 | 中心凹陷、大泡破裂痕、變稀 |
| 餓過頭/過發 | 深色液體層（hooch）、分層、明顯變稀 | 液體浮面或凹陷積液 |
| 污染（判丟） | 任何位置有**毛狀物**、粉紅/橘/黑綠色斑 | 同左；**霉是毛狀/斑點狀，hooch 是液狀** |

- 全麥/裸麥比例高的：表面氣泡少是正常（§4），側面壁泡＋高度＋氣味為主。
- 主麵團 bulk 的判讀另配合 §1（1.8～2 倍、jiggle、網狀）；最後發酵配合 §2 戳洞。
- **加料麵團的偽氣泡** ✅實測：堅果/果乾的鼓包會偽裝成氣泡——實心不透光的突起是料、
  表皮下透亮薄膜才是氣；分不清就對光看或輕按（硬＝堅果，軟彈＝氣）。

**照片內部檢查順序**：安全（污染）→ 漲幅（vs 標記與預期值）→ 氣泡分布 → 質地 →
**跟上次照片比趨勢**（正在爬 vs 正在落，決策完全不同）。

**照片的極限**：看不出氣味摸不出質地——照片只是三分之一證據，必與**氣味描述＋時間軸**
（距上次操作幾小時、該條件的預期時數）交叉才下結論。單張照片無法區分「還沒漲」和
「漲過又全塌」——這就是標記線的價值。

**回報格式範本**（複製用）：
```
對象：波蘭種 / 酸種 / 主麵團 bulk
時間：8/12 21:00（拌後 2h / 距上次餵 12h）
配比：粉100/水100/酵母1g（或 種:粉:水）
溫度：室內 26°C
氣味：微酸帶麥香
照片：側面＋俯視 2 張
今天在家：19:00 後
```

## 六、台灣高溫守則

- 室溫 30～35°C：一切都快。**寧可早看三次，不要晚看一次**——不足能等，過發不能回頭。
- **冷藏麵團的回溫時間也要打折** ✅實測：夏天 30～45 分為限（涼爽季才要 1～1.5 小時）——
  回溫過久＝最後發酵提前開跑，是「照國外食譜時間」的隱形過發來源（佛卡夏第 2 爐教訓）。
- ⚠️ **酵母對照表的溫度欄＝室溫發酵段的溫度，不是冰箱溫度**：冷藏發酵配方的主戰場在
  4～6°C 冰箱內，**與家裡開不開冷氣無關**——室溫只影響「和麵到進冰箱」的啟動段與隔天的
  回溫/最後發酵段。別因為「昨晚比較涼」就加酵母，那會在隔天室溫段變成過發。
  正確做法：**酵母照冷藏時數選檔，室溫差異用「時間」吸收**（涼多等、熱早看）。
- 控麵溫比掐時間有效：攪拌用冰水（`scripts/ddt.py`），麵溫每差 1°C 發酵差 10～15%。
- 30°C+ 建議把發酵搬進冰箱分擔：Cold Proof / Cold Bulk 的選擇與陷阱見 rustic-bread.md §6。
