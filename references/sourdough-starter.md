# 養酸種天然酵母（Sourdough Starter）：從零建立與日常維護

> 這份是「養種」本身的指南；養成後**怎麼用酸種做麵包**（levain 用量、發酵排程）見 `doughs.md` §6。
> 目前為通行流程整理版；Renee 的實測資料待補（見文末【Renee 實測筆記】區）。

## 零、酸種是什麼（先懂原理，心就不慌）

**酸種（sourdough starter）＝ 麵粉＋水養出來的活菌種**，裡面是環境中的**野生酵母＋乳酸菌**。
做麵包時取一部分加進麵團負責膨發——**完全不需要商業酵母**。

- **野生酵母哪裡來？** 到處都是：麵粉袋裡、空氣中、你的手上。看不見不代表不存在——你要做的只是給它粉和水，讓它自己長起來。
- **本質**：你就是在「用罐子養酵母」。加粉加水 → 餵養 → 等它冒泡、翻倍。就這樣，絕大部分時間是放著不管的。

### 時程的真相（心理建設）

| 階段 | 時間 | 說明 |
|---|---|---|
| 建立 | 7～10 天起跳 | 前段用全麥/裸麥粉點火，之後轉白麵粉養（見 §1） |
| **慢的情況** | **2 週以上也完全正常** | 養菌本來就不可預期——溫度、麵粉、環境都有影響。**慢 ≠ 失敗，唯一失敗是發霉（§4）** |
| 養成後 | 持續餵養維護 | 見 §3 日常維護 |

**判斷「可以用了」的標準只有一個組合**：餵後**體積翻倍＋表面和內部滿布氣泡**（完整成熟判斷見 §1）。

### 新手守則：不要想太多
網路上酸種資訊多到會掉進兔子洞，各家說法還互相打架。**挑一份流程（就是這份），照著做完再說。**
大部分的「問題」其實是正常過程（安靜期、假高峰、hooch——都在 §1/§4 有寫），先查表再煩惱。

## 一、從零開始（約 7～10 天；慢的話 2 週+ 也正常）

### 準備物品

**① 麵粉（最重要）**

前期用**全麥粉或裸麥（黑麥）粉**起種——麩皮和胚芽帶的微生物與礦物質多，成功率高、活力強；
穩定後再轉高筋/一般白麵粉維護。**太精緻的粉不適合起種**（養分少、酵母長不大），建議選灰分高一點的粉。

| | 黑麥（裸麥） | 全麥 | 高筋粉 |
|---|---|---|---|
| 養酵難易度（越多星越難） | ★★★ | ★★★★ | ★★★★★ |
| 酸味 | ★★★★★ | ★★★ | ★ |
| 使用範圍 | ★★ | ★★★ | ★★★★★ |

- 黑麥：最好養、酸味最重，但成品用途窄 → 適合**起種點火**。
- 高筋：最難從零養起、風味最溫和、什麼麵包都能配 → 適合**養成後的日常維護**。
- 不同粉養出的酵母風味截然不同，穩定後可以玩配粉。

**② 水**（關鍵是「去氯、留礦物質」，兩個條件缺一不可）

| 水 | 適不適合 | 原因 |
|---|---|---|
| 活性碳過濾水（濾水壺/龍頭濾芯）、礦泉水 | ✅ 最佳 | 去氯但保留礦物質 |
| 自來水煮沸放涼／靜置隔夜 | ✅ 可以 | 氯會散掉（若水廠用的是**氯胺**則煮沸也去不掉，需活性碳濾——台灣多數地區用氯，通常沒問題） |
| 自來水直接用 | ⚠️ 不建議 | 氯抑制菌 |
| **RO 逆滲透水、蒸餾水** | ❌ 不適合 | **太純、礦物質被拔光**——菌需要水中礦物質，缺了會疲弱 |

- 水溫 25～28°C。
- 缺礦物質的實測症狀：前 2～3 天長得不錯，第 4～5 天後完全不長高、只剩表面小泡、質地變稀、酸味明顯。
  ※ 注意這和 Day 3～5 的正常「安靜期」（§1）很像——先照常餵幾天觀察；若**過了一週**還是稀＋不長，且家裡用 RO 水，換活性碳過濾水或礦泉水試。

**③ 容器與攪拌器具**
- 寬口玻璃罐最好（好觀察、好清洗、不殘味），500ml 以上，蓋子虛掩不密封。
- **會碰到酵母的器具先消毒**：沸水川燙、瀝乾放涼備用。

**④ 電子秤（必備）**
- 養天然酵母**一定用重量**，用杯匙量體積失敗率暴增。

**⑤ 橡皮筋／標籤紙**
- 每次餵養攪拌均勻後，**標記酵種高度**——觀察漲幅是判斷活性最可靠的依據。

### 每日流程（室溫 24～26°C 基準）
| 天 | 動作 | 預期狀態 |
|---|---|---|
| Day 1 | 全麥粉 50g ＋ 水 50g 拌勻，室溫放 24h | 沒動靜是正常的 |
| Day 2 | 不餵或攪拌一下即可，續放 24h | 可能出現零星氣泡 |
| Day 3 | 取 50g 舊種＋麵粉 50g＋水 50g（1:1:1），其餘丟棄 | 常見「假高峰」：泡多但多為雜菌產氣 |
| Day 4～5 | 同上，每 24h 餵一次 | **安靜期**：活性反而下降，是菌相交替的正常過程，**不要放棄、不要加料補救** |
| Day 6～7 | 活性上來後改**每 12h 餵一次**（1:1:1） | 餵後 4～8h 體積翻倍、滿布氣泡、有優格/微酸果香 |
| Day 8～10 | 連續 2～3 天「餵後穩定翻倍」→ 養成 | 可開始烤麵包 |

### 成熟判斷（同時滿足）
1. 餵後 **4～8 小時體積翻倍**（台灣夏天可能 3～4 小時就到）
2. 表面與內部滿布氣泡、質地如慕斯
3. 氣味是**優格酸/水果酸香**，不是指甲油或臭味
4. Float test 輔助：取一小匙丟水裡會浮（僅供參考，翻倍與氣味更可靠）

## 二、台灣高溫調整（重要）

室溫 30～35°C 時發酵大幅加速，照國外食譜的 24h 節奏容易**過酸、菌相失衡**：

- **縮短餵養間隔**：活性期改 8～12h 一次，或——
- **拉大餵養比例**：1:1:1 → **1:2:2 或 1:5:5**（種的比例越低、消化越久、越耐放）
- **找涼點**：冷氣房、室內陰涼角落；別放窗邊或電器旁
- 夏天養成速度快（可能 5～7 天就成），但**過酸（刺鼻醋味）時用 1:5:5 連餵兩次「洗種」**回正

## 三、日常維護

### 常烤（每週 2 次以上）→ 室溫養
- 每天固定時間餵 1～2 次（依室溫），比例 1:2:2 起跳
- 用種時機：餵後升到**顛峰（最高點微微回落前）**活性最好

### 偶爾烤（每週 1 次以下）→ 冷藏養（多數家庭適用）
1. 餵完（1:2:2）室溫放 1～2 小時等啟動，進冷藏
2. **每週取出餵一次**：回溫 1h → 照常餵 → 室溫 1～2h → 回冷藏
3. **要烤麵包前 1～2 天喚醒**：取出回溫，連餵 2～3 次（每 12h）到「餵後穩定翻倍」再建 levain

### 建 levain（烤前一晚）
從主種取一小匙（10～20g），按目標量餵成獨立的 levain（如 1:5:5 過夜），主種照常維護不動。這樣主種永遠是備份，失敗只損失 levain。

### 棄種（discard）
- 每次餵養丟掉的部分可冷藏累積，做鬆餅、餅乾、司康、脆餅（未活化的棄種當風味材料，不負責膨發）
- 不想浪費就縮小維護量：主種只留 20～30g 也夠

## 四、疑難排解

| 狀況 | 判讀 | 處理 |
|---|---|---|
| 表面一層灰褐色液體 (hooch) | 餓過頭，正常 | 倒掉或拌回去，照常餵；連續出現→提高餵養比例或縮短間隔 |
| 刺鼻醋味/指甲油味 | 過酸、太餓 | 1:5:5 連餵 2～3 次洗種 |
| Day 3～5 突然沒動靜 | 菌相交替安靜期 | 照常餵，等 |
| 粉紅/橘色斑、黑綠色霉、腐臭 | **污染** | **整罐丟棄重來**，容器煮沸消毒 |
| 冷藏一個月忘記餵 | 通常救得回 | 撇掉表層變色部分，取底部一匙連餵 3～5 次（每 12h）觀察 |
| 翻倍很慢（>12h） | 活性弱 | 連續室溫密集餵（每 12h、1:1:1）2～3 天；水改 28°C 溫水 |

## 五、比例速查（種 : 粉 : 水，重量比）

| 比例 | 到顛峰時間（約 25°C） | 用途 |
|---|---|---|
| 1:1:1 | 4～6h | 快速活化、密集餵養 |
| 1:2:2 | 6～8h | 日常維護主力 |
| 1:5:5 | 8～12h | 過夜 levain、洗種、夏天耐放 |
| 1:10:10 | 12h+ | 長時間外出前、極熱天 |

> 天越熱到顛峰越快；台灣夏天各檔次時間約打 6～7 折。
