# 份量換算：烘焙百分比 (Baker's Percentage)

## 核心觀念
- **麵粉總量永遠 = 100%**。其他每種材料都以「佔麵粉重量的百分比」表示。
- 例：水 80% = 水重是麵粉的 80%；鹽 2% = 麵粉的 2%。
- 換份量時**只改麵粉重量**，其餘材料 = 麵粉重量 × 各自百分比。這樣比例永遠不跑掉。

## 三種換算情境（都用 `scripts/scale_recipe.py`）

### A. 有百分比 → 算克數
給目標麵粉重量與各材料百分比：
```bash
python3 scripts/scale_recipe.py from-percent --flour 250 \
  --pct "高筋麵粉=100,水=80,鹽=2,糖=0.8,橄欖油=4,速發酵母=0.8"
```

### B. 有克數食譜 → 換成別的麵粉重量
腳本自動把「麵粉」抓成 100% 基準，再換到目標麵粉：
```bash
python3 scripts/scale_recipe.py rescale --to-flour 150 \
  --recipe "高筋麵粉=500,水=400,鹽=10,速發酵母=4"
```

### C. 有克數食譜 → 直接乘倍數
```bash
python3 scripts/scale_recipe.py rescale --factor 2 \
  --recipe "高筋麵粉=500,水=400,鹽=10,速發酵母=4"   # 加倍
python3 scripts/scale_recipe.py rescale --factor 0.5 \
  --recipe "高筋麵粉=500,水=400,鹽=10,速發酵母=4"   # 減半
```

> 材料名含「麵粉 / flour / 粉」者會被視為基準；多種粉時所有粉相加當 100%。若判斷不到，用 `--flour-key 高筋麵粉` 明確指定。

## 手算公式
- 目標某材料克數 = 目標麵粉重量 × (該材料原克數 ÷ 原麵粉克數)
- 縮放倍數 = 目標麵粉重量 ÷ 原麵粉重量；所有材料 × 這個倍數。

## 烤模 → 麵粉量（麵包，Renee 佛卡夏經驗）
**麵糰量由烤模底面積決定**（不是開口；梯形模看底部）。成品約 2.5cm 厚時：
| 烤模 | 底面積 | 建議麵粉 |
|---|---|---|
| 10.5×18.5cm | 194 cm² | 120 g |
| 鋁箔盒（底 16.9cm） | 286 cm² | 180 g |
| CHEFMADE 方模（底 18.7cm） | 350 cm² | 220 g |
| 大烤盤 30×40cm | 1200 cm² | 500 g+ |

估算：**麵粉量 (g) ≈ 底面積 (cm²) × 0.4～0.45**（高水合佛卡夏）。其他麵包依厚度與種類調整。

## 酵母隨發酵時間反比（最重要的調整）
份量放大縮小時**麵粉/水/鹽/糖/油等比例乘就好**，但**酵母要另外依發酵時間與室溫決定**，不是單純跟著乘。時間越長、天氣越熱 → 酵母越少。

低糖速發酵母對照（以麵粉%計，參考佛卡夏冷藏發酵）：
| 冷藏發酵時間 | 涼爽 ≤25°C | 夏天 30～35°C |
|---|---|---|
| 當天室溫 3～5h | 1.2～1.5% | 1% |
| 12 小時 | 1% | 0.7～0.8% |
| 18 小時 | 0.7% | 0.5～0.6% |
| 24 小時 | 0.5% | 0.4% |
| 36～48 小時 | 0.3～0.4% | 0.25～0.3% |

> **小數值酵母（<1g）用酵母水稀釋法**：10g 酵母 + 100g 水攪勻，每 10g 酵母水 = 1g 酵母；**總水量記得扣掉用掉的酵母水**。
