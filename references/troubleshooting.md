# 失敗症狀對照表（做壞了先查這裡）

> 症狀 → 最可能原因（按可能性排序）→ 對策。Renee 實戰驗證過的標 ✅。
> 「養酸種」本身的問題（hooch、發霉、沒動靜）查 `sourdough-starter.md` §4；這份是**麵包本體**的失敗。
> 診斷心法：**先懷疑水合度和發酵程度，再懷疑其他**——八成的失敗出在這兩個。

## 零、出爐照片檢查順序（使用者傳成品照時先跑這個）

### ⚠️ 先講清楚「open crumb」是什麼——它是光譜，不是單一目標

**「開放組織」涵蓋兩端，兩端都合格**：

| 型態 | 長相 | 別名 |
|---|---|---|
| **均勻型開放** | 氣孔開但大小一致、分布規則 | refined crumb（近年社群主流） |
| **極端不規則型** | 大小孔交錯、超大孔、壁薄如膜 | **molten crumb** / wild crumb |

⚠️ **常見混淆**：網路上說「要做出 open crumb 就得高水合」的，多半心裡想的是**極端那一端**
（molten crumb）。**一般的開放組織 70% 水合就做得到，不需要高水合。**
使用者說「想要開放組織」時**先問是哪一端**——目標不同，該動的變因完全不同。

### 🎯 追開放組織時，該動哪個變因（優先序）

Trevor Wilson（《Open Crumb Mastery》）的排序，**與直覺相反但值得照做**：

> **發酵 ≈ 麵團手法 ＞＞＞ 水合（"nothing but a distant third"）**

- **第一順位：發酵**（Wilson 光 bulk fermentation 就寫了約 80 頁）
- **第二順位：手法**（結構建立、摺疊、整形張力、濕麵團操作）
- **第三順位（差很遠）：水合**
- 其他同樣有份量的：**酸種活力**、麵粉

⚠️ **這條直接對抗一個很強的誘惑**：水合是最容易調的數字（改一下配方就好），
所以大家都先動它——但它的邊際效益最低。**組織不夠開時，先回頭查發酵夠不夠
（含 fool's crumb 檢查）與手法有沒有漏掉，再考慮加水。**

**判讀前先問兩件事校準期望值**：
1. **目標路線**（歐包開放組織 vs 甜麵包/吐司細緻均勻）——同一張剖面照，兩個路線的判讀方向相反。
2. **配方組成**（✅實測＋文獻支持）：全麥/裸麥比例越高、配料（乾果堅果）越多，氣孔天花板越低——
   例：31% 全麥＋70g 乾果的鄉村麵包，「中小孔均勻」就是滿分，換什麼設備都到不了 open crumb；
   別把組成決定的組織誤判為「水太少」而盲目加水。大孔追求請用 lean 配方（無全麥無配料）。
   - **機制（文獻）**：麩皮顆粒像小刀片切斷筋膜、大片麩皮會刺破氣室；全穀粉還要用較少的
     有效筋去撐起較重的麩皮胚芽 → 保氣力下降。配料同理：塊狀物打斷筋網、降低 oven spring。
   - **可緩解、但不可消除**：全穀先浸泡（soaker）、提高水合、摻高筋粉、降低全穀比例；
     配料切小塊、先泡再瀝乾、**越晚加越好**（bulk 後段或預整形時加，對筋網干擾最小）。
   - **選超細研磨的全粒粉**：破壞源自麩皮顆粒的物理切割，顆粒越細破壞越小——
     同比例全麥下，超細粉的氣孔天花板明顯高於粗磨粉（見 flour-notes 全穀段）。
   - **篩麩皮＋soaker 回加（手工版的超細粉）**：全粒粉過篩 → 粗麩皮單獨加水泡軟（1:1，30 分以上）
     → 麵團先用**篩過的細粉**建立筋網 → **摺疊後段**再把軟化麩皮拌回。營養風味全留，
     但麩皮不在筋網形成期切它。想維持高全麥比例又要開放組織時，這是主力手段。
   - ⚠️ **別把全穀比例當硬牆**：文獻記載 **50% 以上全穀仍可做出開放組織**，前提是技術與發酵到位——
     高比例只是「更難」不是「不可能」。遇到組織不夠開放時，先窮盡上述手段，
     再考慮降低全穀比例（那會改變麵包的身分）。
   - 配料用量通行上限：**佔麵粉的 10～20%**（香料 1～5%）——超過就是拿組織換風味的取捨。

**外觀照**（出爐即可拍）：
1. 挺度：高寬比——扁塌 → 查 §五「扁＋組織細密」鏈
2. 割線/爆口：開了沒？往預期方向爆還是側爆/底爆？→ 查 §三
3. 上色：深淺與均勻度 → 查 §四
4. 底部：有無焦黑 → 查 §四
5. **Blisters（表皮小水泡狀凸起）**：見下方——**是製程的證據，不是品質的證據**

**Blisters（起泡皮）是什麼、代表什麼**（✅已查證）：
- **成因**：**冷藏發酵**時 CO₂ 滲進並滯留在麵團表層（越冷溶得越多）；進爐後 CO₂ 受熱膨脹，
  但外皮已開始定型把它擋住 → 頂成一顆顆小泡。**冷藏越久越明顯。**
- 🚨 **它只證明「有經過冷藏發酵」，不證明發酵程度、組織或風味**——
  與「有爆口/ear ≠ 發酵夠」同類，都是**把製程證據當品質證據**的陷阱。
- ⚠️ **好壞是文化不是技術**：美國視為成功象徵、專門追求；**法國常視為瑕疵**。
  使用者說「想要 blisters」＝想要那個外觀，**照冷藏發酵去給流程即可，別當品質目標**。
- **反向推論可用**：**沒冷藏卻出現明顯 blisters ＝ 可疑**，先確認是不是看錯
  （一般表面凸起、浮粉結塊、配料頂出來都可能被誤認）。

**剖面照**（⚠️ 完全放涼再切——小顆 45 分、標準 1 小時，太早切的「濕黏」不算數；
**拍「單一平整切面」正對鏡頭** ✅實測——切半後掰開對拍的照片會在兩半交界處產生假的
「分層帶/空洞線」，撕裂面配料裸露更會加強錯覺）：
1. 氣孔分布：均勻度、大小（對照目標路線）
2. 皮下有無一圈大空洞 → §五
3. 底部有無密實帶（沉澱層）→ 發酵不足或整形壓實
4. 中心質地：熟透 vs 濕黏反光 → §五
5. 皮的厚度 → §四

### 剖面 → 發酵程度判定表（The Sourdough Journey "How to Read a Sourdough Crumb"）

> ⚠️ **這張表推翻一個很常見的直覺：大氣孔常常代表「發酵不足」，不是成功。**
> 開放組織的大孔是**均勻分布的中大孔**；發酵不足的大孔是**孤立的洞穴／隧道，旁邊還有密實區**。
> 判斷「這爐發得夠不夠」時以本表為準，別看到洞就當成功。

| 判定 | 剖面特徵 | 形狀 |
|---|---|---|
| **嚴重不足** | 密實、**濕黏（gummy）** | 撐得住 |
| 不足 | 密實＋**隧道（tunneling）** | 撐得住 |
| 不足 | 海綿狀＋**大洞穴（caverns）** | 撐得住 |
| 不足 | **密實區與巨大氣孔並存**、分布極不均 | 撐得住 |
| 略不足 | 隧道＋**剖面呈金字塔形**（頂部尖） | 頂偏尖 |
| ✅ **剛好** | 略偏緊實但**均勻**（slightly closed） | 飽滿 |
| ✅ **剛好** | **開放不規則**（open, irregular crumb） | 飽滿 |
| ✅ **剛好** | **molten crumb**（孔洞如熔融流動、壁薄） | 飽滿 |
| ✅ **剛好** | **wild crumb**（大小孔交錯、最狂野） | 飽滿 |
| ✅ 充分發酵 | 稍緊實但均勻（somewhat tight） | 飽滿 |
| 略過發 | **孔洞其實不錯，但形狀開始塌** | 走形、變寬 |
| **嚴重過發** | 密實＋**扁平** | 扁 |

### 🚨 傻瓜氣孔（fool's crumb）——最容易誤判成功的發酵不足

> **長相：整體是緊實細密的小孔，但「上半部／靠近上皮處」有幾個孤立的大孔，下半部明顯更密實。**
> 它會讓人以為「有大孔＝開放組織成功了」，實際上是**發酵不足**。英文烘焙圈直接叫它
> **fool's crumb（傻瓜氣孔）**——名字就是在講它會騙人。

**成因**：麵團沒發夠，筋還很強、產氣也不足且分布不均 → 進爐後氣體無處可去，
在最弱的地方（多半靠近上皮）撐開幾個孤立大洞，**其餘區域的氣室仍然很小很緊**，
底部因為受壓最多而最密實。

**⚠️ 判讀者最常犯的四個合理化（我犯過，別再犯）**：

| 錯誤的想法 | 為什麼錯 |
|---|---|
| 「上大下小是正常的，氣體本來就往上跑」 | ❌ **這正是 fool's crumb 的定義**。輕微梯度才是正常，**明顯的上開下密就是徵象**，不要解釋掉 |
| 「孔是圓的、輪廓平滑，不是撕裂狀，所以不是發酵不足」 | ❌ **圓孔不能排除發酵不足**。發酵不足的孤立大洞常常就是圓的。這條判準是憑空想像的，來源根本沒有 |
| 「大孔周圍的組織是正常充氣的，不算密實區」 | ❌ **密實是相對的**。緊實細密的小孔矩陣**本身就是那個「密實區」**——要比的是「發好的麵包該長什麼樣」，不是比旁邊有沒有更糟 |
| 「沒有隧道、沒有濕黏，所以不是發酵不足」 | ❌ 那是**嚴重**發酵不足的徵象。**輕中度發酵不足就長成緊實細密＋零星大孔**，沒有濕黏也沒有明顯隧道 |

**對策**：延長主發酵，讓氣體有時間**均勻**分布（不是延長最後發酵）。

### 🔒 強制步驟：判定發酵程度前，先描述「壁」

> **⚠️ 給 AI：這一步不可跳過，也不可先講結論再補理由。**
> 收到剖面照時，**第一句話必須是對「孔與孔之間那層 material」的描述**，
> 描述完才能給判定。已經在此連續失誤兩次，兩次都是**用孔洞的數量與分布推論**，
> 而那些**全部都會騙人**。

| 觀察點 | ✅ 發酵到位 | ❌ 發酵不足 |
|---|---|---|
| **形狀** | 相鄰氣孔之間只隔著一道**窄脊** | 孔之間是**塊狀實體** |
| **光** | 表面**有反光／光澤** | **霧面**、無光 |
| **熟度** | **熟透如卡士達（custardy）**，壁是「定型」的 | **生麵團感（doughy）** |
| **界線** | 每顆氣孔輪廓**清晰可描** | **糊在一起**、界線模糊 |
| **整體印象** | **薄膜構成的泡沫網絡** | **實心麵團上打洞** |
| （口感佐證） | 蓬鬆 | 使用者會說「**黏**」「組織黏在一起」 |

> **最快的一句話判準：「孔之間是『脊』還是『塊』？」**
> 脊＝到位，塊＝不足。這比「孔大不大、多不多、均不均」可靠得多。

**核心事實（文獻）**：
> 發酵到位的麵包，**孔與孔之間的麵團是薄的、半透明的、熟透的**；
> 發酵不足的麵包是**厚而帶麵團感的壁**，配上大小不一的孔與黏的質地。

**兩種長相要能分辨**：
- **泡沫（foam）**＝薄膜構成的網絡，整體看起來輕 → 發酵到位
- **實心體上打洞**＝孔像是被戳進一塊實心麵團裡，孔之間是塊狀的 → 發酵不足

**⚠️ 已知會誤導的表象（不可作為判準）**：
- ❌ 孔很多 → 數量不等於蓬鬆，實心體上也能有很多洞
- ❌ 孔分布均勻 → 均勻的厚壁還是厚壁
- ❌ 孔一路分布到底部、沒有明顯密實帶 → 整塊都厚壁時就不會有「帶」
- ❌ 有爆口/ear、形狀挺 → 那證明筋強與割線好，**發酵不足的麵團筋更強、更容易爆得漂亮**
- ❌ 孔是圓的不是撕裂狀 →（見上方合理化對照表，此判準已駁回）

**三條判讀規則（比記十二張圖有用）**：

1. **密實出現在兩端，用「形狀」分辨**——
   密實＋**扁塌** → **過發**；密實＋**撐得住高度**（常伴濕黏、隧道、孤立大洞）→ **不足**。
2. **過發是「先垮形狀，後垮組織」**——所以**挺度是比氣孔更早的過發警訊**。
   看到「孔洞漂亮但麵包變寬變扁」＝已經略過發，下次提早收。
3. **「剛好」的範圍很寬**（從 slightly closed 到 wild crumb 都算合格）——
   **均勻偏緊實不是失敗**。組織夠不夠開放是「路線與配方」的問題（見上方組成天花板），
   發酵夠不夠是「有沒有隧道／洞穴／密實區／濕黏／傻瓜氣孔」的問題，**兩件事別混為一談**。
   ⚠️ 但「均勻偏緊實」的合格前提是**真的均勻**——上開下密就不是均勻，是 fool's crumb。
4. 🔒 **看「壁」，不看「孔」——這是唯一可靠的判準，且必須第一個做**。
   詳見下方強制步驟。孔的大小、數量、分布**全都會騙人**；孔與孔之間那層material 不會。

**適用範圍**：剖面特徵是物理現象，**酸種與商業酵母麵團通用**。
但「該發到什麼程度」的終點值不同——酸種看 `fermentation-guide.md` §1 雙因子法，
商業酵母看 1.8～2 倍。**判讀用同一張表，設定目標用不同的尺。**

檢查完拿著症狀進下方各區查表。**成品照是最好的實測記錄**——判讀完把結論記進對應的
實測區（flour-notes 日誌、rustic-bread 相關章節）。

## 一、攪拌／麵團手感

| 症狀 | 可能原因 | 對策 |
|---|---|---|
| 攪拌時牽絲一拉就斷、像爛泥 ✅ | 水太多（75%+）、筋撐不住 | 降回 65～70% 安全區；要高水合就用後加水法＋多摺疊（rustic-bread.md §5） |
| 麵團偏硬、捲不動攪不動 | 水太少，或這款粉吸水特別高 | 分次補水 2～5%（每次 1%），看狀態不硬湊；記進 flour-notes.md |
| 黏手到完全無法操作 | 高水合正常現象／筋還沒養成 | 濕手＋刮板操作、用摺疊代替揉；筋出來後黏性會降 |
| 攪拌機打到麵團發熱、越打越爛 | 過度攪拌斷筋、麵溫過高 | 控麵溫（scripts/ddt.py）；打到八分膜就停，剩下靠摺疊補 |

## 二、發酵

| 症狀 | 可能原因 | 對策 |
|---|---|---|
| 完全發不起來 | 酵母失活（過期／水溫 >40°C 燙死）、環境太冷、鹽直接堆在酵母上 | 溫水+糖測酵母活性（10 分起泡沫才算活）；鹽和酵母分開放 |
| 發太快、有酒味 | 台灣高溫＋照國外食譜的酵母量 | 減酵母（scaling.md 對照表）、改冷藏發酵、找涼點 |
| 發酵往旁邊攤、不往上長 ✅ | 筋性不足撐不住氣體（多半是水太多） | 補摺疊養筋；下次降水合 |
| Cold Bulk 隔天「看起來發了其實沒完成」✅ | 冷藏壓低酵母活性，bulk 中斷 | 回溫＋補摺疊，確認真的到 1.8～2 倍再整形（rustic-bread.md §6） |
| 發過頭：塌陷、酸臭、按下去洩氣 | 時間太長／溫度太高／酵母太多 | 不可逆。改整形成佛卡夏或披薩，別強求挺度；下次用 ferment.py adjust 對時間 |

## 三、整形／割線

| 症狀 | 可能原因 | 對策 |
|---|---|---|
| 整形站不住、要一直撒粉救場 ✅ | 水太多、筋不夠——撒粉是治標 | 回去補摺疊，或下次降水合；撒粉太多會夾進麵團變生粉層（shaping.md §7） |
| 割線亂爆、從側面爆開 ✅ | 割太淺（<1cm）、表面太乾、收口沒捏緊、發酵不足 | 噴水霧回潤再割；十字、1cm、下刀果斷；收口確實捏緊 |
| 割線完全沒開、表面平 | 過發（沒力氣了）、無蒸氣、表面張力不足 | 對照發酵判斷（fermentation-guide.md）；加蓋補蒸氣（rustic-bread.md §4） |
| 出爐歪一邊、形狀不對稱 | 整形張力不均、割線深淺不一 | 收緊時每個方向力道一致；轉 90° 多收幾輪 |

## 四、烘烤

| 症狀 | 可能原因 | 對策 |
|---|---|---|
| 表面上色好了、中心卡在 88°C 上不去 ✅ | 氣炸烤箱熱傳限制＋圓球麵包中心最遠 | 後段降溫慢烤：170～180°C＋蓋鋁箔拉長時間，補到 94°C 以上（rustic-bread.md §4） |
| 上色太快、快焦了裡面還沒熟 | 氣炸鍋乾熱強；糖／奶多的配方更明顯 | 降 10～20°C、提早蓋鋁箔；下次直接用換算後溫度（convert.py） |
| 皮太厚太硬像盔甲 | 低溫烤太久、全程無蒸氣 | 前段加蓋蒸氣 10～12 分；縮短總時間、提高前段溫度 |
| 底部焦黑 | 離下加熱管太近、深色烤盤吸熱 | 墊雙層烤盤或移高一層 |
| 沒有 oven spring（進爐不長高） | 沒預熱 ✅、過發、無蒸氣殼太早定型 | 氣炸鍋做麵包**務必預熱 10～15 分**；鍋＋鋁箔一起預熱 |

## 五、出爐後剖面（麵包會說話）

| 症狀 | 可能原因 | 對策 |
|---|---|---|
| 扁＋組織細密 ✅ | 全鏈問題：水太多 → 筋撐不住 → 每一步都在漏氣 | 回 69% 安全區重建基準（rustic-bread.md §3） |
| 組織細密像饅頭（但不扁） | 整形排氣過度、水合偏低、發酵不足 | 歐包要輕整形不排氣（shaping.md）；確認 bulk 到位 |
| **皮下巨大空洞／外皮架空（flying crust）** | 見下方專節——**首因是發酵不足，不是過發** | 見下方專節 |
| 中心濕黏像沒熟 | 沒烤到中心 96～98°C、出爐太早切 | 用探針溫度計；**完全放涼（至少 1 小時）再切**——餘熱還在煮 |
| 酸味過重（酸種麵包） | 發酵過久、溫度偏高、種本身太酸 | 縮短冷藏時間；種先洗（1:5:5 連餵）再建 levain |
| 隔天就乾硬老化 | 水合低、直接法、無保濕手段 | 改湯種／波蘭種（doughs.md）；放涼後密封，回烤 3 分鐘復活 |

### 🚨 皮下巨大空洞（flying crust）——**看起來最像 open crumb 的失敗型態**

**長相**：上皮下方一個／一排**巨大空洞**，外皮**架在空的上面**、與麵心分離；
**下半部相對細密**；空洞內壁**光滑微黃像上了一層膜**。

**⚠️ 怎麼跟真開放組織分辨**（孔都很大，但成因相反）：

| | 真開放組織 | 皮下巨大空洞 |
|---|---|---|
| 成因 | **均勻產氣** | **氣體上浮聚集到同一處** |
| 大孔位置 | **整個剖面都有** | **集中在上皮下** |
| 其他區域 | 也是中大孔，壁一致地薄 | **相對細密** |
| 孔的內壁 | 薄膜網絡（脊） | **光滑如膜**（單一大氣泡撐開後糊化的面） |

**成因優先序（重要，本檔曾經寫反）**：

1. **🥇 發酵不足**（首因）——麵團進爐時**仍保有太多爆發力**，氣體沿**阻力最小處**集中膨脹
   撐成幾個巨大洞穴；**底部來不及膨脹就定型，留下密實的小孔層**。
   ⚠️ 這與 §0 的 12 格表一致：「Dense areas and giant holes」「Spongy crumb and caverns」
   **兩格都掛在 Underproofed 底下**。
   → **對策：延長主發酵**（不是最後發酵）。
2. **🥈 高水合但筋網與發酵沒跟上**——**水多只提高延展性，不會自動產生漂亮大孔**。
   筋網強度、發酵成熟度、摺疊時機任一沒跟上，加的水就變成
   **「幾個巨大洞＋其他地方很密」**。
   ⚠️ 這是 Wilson「水合是 distant third」的**具體後果**：
   **只加水不配套，得到的不是 open crumb，是這個。**
   → 對策：先把發酵與摺疊做到位，再談加水。
3. **🥉 整形捲入空氣／表皮沒貼合**——整形時包進大氣泡又沒拍掉，形成獨立空腔。
   → 對策：預整形時輕拍排掉特別誇張的大泡、收口確實捏緊貼合。
4. （次要）表面結殼太早——外皮定型後麵心還在長而拉開 → 前段加蓋補蒸氣。

**❌ 不要把「過發」列為首因**：過發的剖面是**密實＋扁平**（§0 12 格表），
不是巨大空洞。⚠️ 麵包又低又寬**不足以判過發**——高水合的鬆軟麵團本來就會攤，
且 ciabatta 類本來就低寬。**形狀是弱證據，判定回到「壁」與「氣孔分布」。**

> 📌 **若麵包本身就是 ciabatta 類**（大孔是目的）：大孔不是缺陷，
> 但**外皮架空＋底部密實**對 ciabatta 一樣是缺陷，判準不變。
