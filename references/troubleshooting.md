# 失敗症狀對照表（做壞了先查這裡）

> 症狀 → 最可能原因（按可能性排序）→ 對策。Renee 實戰驗證過的標 ✅。
> 「養酸種」本身的問題（hooch、發霉、沒動靜）查 `sourdough-starter.md` §4；這份是**麵包本體**的失敗。
> 診斷心法：**先懷疑水合度和發酵程度，再懷疑其他**——八成的失敗出在這兩個。

## 零、出爐照片檢查順序（使用者傳成品照時先跑這個）

**判讀前先問兩件事校準期望值**：
1. **目標路線**（歐包開放組織 vs 甜麵包/吐司細緻均勻）——同一張剖面照，兩個路線的判讀方向相反。
2. **配方組成** ✅實測：全麥/裸麥比例越高、配料（乾果堅果）越多，氣孔天花板越低——
   例：31% 全麥＋70g 乾果的鄉村麵包，「中小孔均勻」就是滿分，換什麼設備都到不了 open crumb；
   別把組成決定的組織誤判為「水太少」而盲目加水。大孔追求請用 lean 配方（無全麥無配料）。

**外觀照**（出爐即可拍）：
1. 挺度：高寬比——扁塌 → 查 §五「扁＋組織細密」鏈
2. 割線/爆口：開了沒？往預期方向爆還是側爆/底爆？→ 查 §三
3. 上色：深淺與均勻度 → 查 §四
4. 底部：有無焦黑 → 查 §四

**剖面照**（⚠️ 完全放涼再切——小顆 45 分、標準 1 小時，太早切的「濕黏」不算數；
**拍「單一平整切面」正對鏡頭** ✅實測——切半後掰開對拍的照片會在兩半交界處產生假的
「分層帶/空洞線」，撕裂面配料裸露更會加強錯覺）：
1. 氣孔分布：均勻度、大小（對照目標路線）
2. 皮下有無一圈大空洞 → §五
3. 底部有無密實帶（沉澱層）→ 發酵不足或整形壓實
4. 中心質地：熟透 vs 濕黏反光 → §五
5. 皮的厚度 → §四

檢查完拿著症狀進下方各區查表。**成品照是最好的實測記錄**——判讀完把結論記進對應的
實測區（flour-notes 日誌、rustic-bread 相關章節）。

## 一、攪拌／麵團手感

| 症狀 | 可能原因 | 對策 |
|---|---|---|
| 攪拌時牽絲一拉就斷、像爛泥 ✅ | 水太多（75%+）、筋撐不住 | 降回 65～70% 安全區；要高水合就用後加水法＋多摺疊（rustic-bread.md §5） |
| 麵團偏硬、捲不動攪不動 | 水太少，或這款粉吸水特別高 | 分次補水 2～5%（每次 1%），看狀態不硬湊；記進 flour-notes.md |
| 黏手到完全無法操作 | 高水合正常現象／筋還沒養成 | 濕手＋刮板操作、用摺疊代替揉；筋出來後黏性會降 |
| 攪拌機打到麵團發熱、越打越爛 | 過度攪拌斷筋、麵溫過高 | 控麵溫（scripts/ddt.py）；打到八分膜就停，剩下靠摺疊補 |

## 二、發酵

| 症狀 | 可能原因 | 對策 |
|---|---|---|
| 完全發不起來 | 酵母失活（過期／水溫 >40°C 燙死）、環境太冷、鹽直接堆在酵母上 | 溫水+糖測酵母活性（10 分起泡沫才算活）；鹽和酵母分開放 |
| 發太快、有酒味 | 台灣高溫＋照國外食譜的酵母量 | 減酵母（scaling.md 對照表）、改冷藏發酵、找涼點 |
| 發酵往旁邊攤、不往上長 ✅ | 筋性不足撐不住氣體（多半是水太多） | 補摺疊養筋；下次降水合 |
| Cold Bulk 隔天「看起來發了其實沒完成」✅ | 冷藏壓低酵母活性，bulk 中斷 | 回溫＋補摺疊，確認真的到 1.8～2 倍再整形（rustic-bread.md §6） |
| 發過頭：塌陷、酸臭、按下去洩氣 | 時間太長／溫度太高／酵母太多 | 不可逆。改整形成佛卡夏或披薩，別強求挺度；下次用 ferment.py adjust 對時間 |

## 三、整形／割線

| 症狀 | 可能原因 | 對策 |
|---|---|---|
| 整形站不住、要一直撒粉救場 ✅ | 水太多、筋不夠——撒粉是治標 | 回去補摺疊，或下次降水合；撒粉太多會夾進麵團變生粉層（shaping.md §7） |
| 割線亂爆、從側面爆開 ✅ | 割太淺（<1cm）、表面太乾、收口沒捏緊、發酵不足 | 噴水霧回潤再割；十字、1cm、下刀果斷；收口確實捏緊 |
| 割線完全沒開、表面平 | 過發（沒力氣了）、無蒸氣、表面張力不足 | 對照發酵判斷（fermentation-guide.md）；加蓋補蒸氣（rustic-bread.md §4） |
| 出爐歪一邊、形狀不對稱 | 整形張力不均、割線深淺不一 | 收緊時每個方向力道一致；轉 90° 多收幾輪 |

## 四、烘烤

| 症狀 | 可能原因 | 對策 |
|---|---|---|
| 表面上色好了、中心卡在 88°C 上不去 ✅ | 氣炸烤箱熱傳限制＋圓球麵包中心最遠 | 後段降溫慢烤：170～180°C＋蓋鋁箔拉長時間，補到 94°C 以上（rustic-bread.md §4） |
| 上色太快、快焦了裡面還沒熟 | 氣炸鍋乾熱強；糖／奶多的配方更明顯 | 降 10～20°C、提早蓋鋁箔；下次直接用換算後溫度（convert.py） |
| 皮太厚太硬像盔甲 | 低溫烤太久、全程無蒸氣 | 前段加蓋蒸氣 10～12 分；縮短總時間、提高前段溫度 |
| 底部焦黑 | 離下加熱管太近、深色烤盤吸熱 | 墊雙層烤盤或移高一層 |
| 沒有 oven spring（進爐不長高） | 沒預熱 ✅、過發、無蒸氣殼太早定型 | 氣炸鍋做麵包**務必預熱 10～15 分**；鍋＋鋁箔一起預熱 |

## 五、出爐後剖面（麵包會說話）

| 症狀 | 可能原因 | 對策 |
|---|---|---|
| 扁＋組織細密 ✅ | 全鏈問題：水太多 → 筋撐不住 → 每一步都在漏氣 | 回 69% 安全區重建基準（rustic-bread.md §3） |
| 組織細密像饅頭（但不扁） | 整形排氣過度、水合偏低、發酵不足 | 歐包要輕整形不排氣（shaping.md）；確認 bulk 到位 |
| 皮下一圈大空洞 | 整形沒收實（表皮和麵心分離）、過發、表面結殼太早 | 整形時收緊貼合；最後發酵蓋濕布防乾 |
| 中心濕黏像沒熟 | 沒烤到中心 96～98°C、出爐太早切 | 用探針溫度計；**完全放涼（至少 1 小時）再切**——餘熱還在煮 |
| 酸味過重（酸種麵包） | 發酵過久、溫度偏高、種本身太酸 | 縮短冷藏時間；種先洗（1:5:5 連餵）再建 levain |
| 隔天就乾硬老化 | 水合低、直接法、無保濕手段 | 改湯種／波蘭種（doughs.md）；放涼後密封，回烤 3 分鐘復活 |
